## Overview

Valerie is a conversational assistant powered by generative AI. The project covers the backend service behind the chatbot, the web client people talk to it through, and the data collection work that supports it.

## My role

- Built the backend service and its APIs.
- Built the web client.
- Prepared supporting data with Python notebooks.

## Stack

- **Service:** Go, using gRPC for server-to-server communication and GraphQL for server-to-client communication.
- **API development:** schema-first, with resolvers and models generated by gqlgen.
- **Data:** MongoDB for storage and Redis for caching.
- **Client:** Next.js with React and Tailwind CSS.

## Outcomes

- A working hybrid communication model: efficient internal messaging over gRPC with a flexible GraphQL API at the edge.
- Hands-on experience shaping a backend around AI-driven, conversational responses.
