## Overview

TiKACore is the administrative core system for an organisation: the place staff go to manage day-to-day records, in one system with a single source of truth.

## My role

I work across the whole product:

- The backend service and its API.
- The web dashboard that staff use.
- The user manual that documents the product for its users.

## Stack

- **Service:** Go with a GraphQL API generated by gqlgen, layered so that business logic stays independent of the database and the transport.
- **Data:** PostgreSQL with versioned migrations.
- **Dashboard:** React and TypeScript, built with Vite and styled with Tailwind CSS.

## Outcomes

- A product in continuous development for more than a year.
- One schema-first API contract shared by the service and the dashboard, which keeps the two in step as features are added.
- Documentation maintained alongside the product, so new features ship with their manual pages.
